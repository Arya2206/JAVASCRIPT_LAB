## 📌 About This Repository

This repository contains a collection of **JavaScript and jQuery practical experiments** developed as part of web development practical work.

The experiments cover JavaScript fundamentals, functions, arrays, objects, DOM manipulation, events, form validation, browser storage, JSON, AJAX, timers, ES6 modules, and jQuery.

Each experiment focuses on a specific JavaScript concept and demonstrates its practical implementation using **HTML, CSS, JavaScript, and jQuery**.

## 💻 How to Run

1. Clone or download this repository.
2. Open the required experiment folder.
3. Open the HTML file in a web browser.
4. For experiments using **JSON, Fetch API, AJAX, or ES6 modules**, run the files using a local server such as **VS Code Live Server**.
5. Use the browser's **Developer Tools → Console** to view console outputs where required.
